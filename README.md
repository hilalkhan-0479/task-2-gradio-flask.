# Logistic Regression with Gradio and Flask

Logistic regression on two classification datasets, with a web UI built in both Gradio and Flask.

## Datasets
- `heart_disease.csv`: predicts heart risk from age, cholesterol, blood pressure, smoker
- `loan_approval.csv`: predicts loan approval from income, credit score, loan amount, employed

## Setup
pip install -r requirements.txt

## Run
Open `logistic_regression.ipynb` in Jupyter and run the cells in order.
- Gradio UI opens inside the notebook.
- Flask UI runs at http://127.0.0.1:5001/heart and /loan
